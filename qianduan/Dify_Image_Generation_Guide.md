# Dify聊天机器人图片生成配置指南

## 1. 在Dify中配置图片生成功能

### 登录Dify管理后台
1. 访问您的Dify实例: http://43.140.245.165:8993
2. 使用管理员账户登录

### 配置应用支持图片生成
1. 进入您的聊天机器人应用设置
2. 在"提示词编排"或"Prompt Engineering"部分，添加以下系统提示：

```
你是一个电磁场课程的专业助手，能够回答问题、生成图表和绘制电磁场示意图。

当用户要求生成图片、图表或示意图时，请使用以下格式之一：

1. 对于图片URL：
   ![图片描述](图片URL)

2. 对于需要用户点击查看的图片：
   [点击查看图片: 描述](图片URL)

3. 对于重要的示意图或图表：
   下面的图表示[图表内容]:
   ![图表](图表URL)

你可以生成的图片类型包括：
- 电磁场线分布图
- 电磁波传播示意图
- 电路图
- 物理公式示意图
- 3D模型示意图

当生成图片后，请提供简短的解释说明图片内容。
```

### 配置图像生成能力（如果您的Dify支持）
1. 在"工具"或"Tools"部分，添加图像生成工具
2. 配置图像生成API（如DALL-E, Midjourney, Stable Diffusion等）
3. 设置图像生成参数（尺寸、质量等）

### 配置知识库（可选）
1. 上传电磁场课程相关的知识文档
2. 配置向量数据库以支持准确回答

## 3. 前端已实现的功能

### 图片显示和交互
1. 自动识别和显示聊天消息中的图片URL
2. 支持多种图片格式：JPG, PNG, GIF, WebP
3. 支持Base64编码的图片
4. 支持Markdown格式的图片链接 `![alt](url)`

### 图片预览功能
1. 点击图片可以全屏预览
2. 预览模式支持点击背景或关闭按钮退出
3. 图片自适应屏幕大小

### 响应式设计
1. 图片容器自适应聊天窗口宽度
2. 图片悬停效果，显示放大镜图标
3. 全屏预览适配不同屏幕尺寸

## 4. 故障排除

### 图片不显示
1. 检查Dify返回的图片URL是否可访问
2. 确认图片格式是否受支持
3. 检查浏览器控制台是否有错误信息

### 图片预览不工作
1. 检查JavaScript是否正确加载
2. 确认没有其他CSS样式冲突
3. 检查事件监听器是否正确绑定

## 5. 高级配置（可选）

### 自定义图片样式
可以修改以下CSS类来自定义图片显示效果：
- `.dify-chat-message img` - 基本图片样式
- `.image-container` - 图片容器样式
- `.image-preview-modal` - 预览模态框样式

### 添加图片操作功能
可以在图片预览中添加：
- 下载按钮
- 分享功能
- 缩放控制

### 图片懒加载
对于大量图片的场景，可以实现懒加载功能以提高性能。
